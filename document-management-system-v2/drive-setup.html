3. Google Drive 승인 및 연결

연결 상태를 불러오는 중입니다.

Google Cloud에서 OAuth 클라이언트 만드는 순서

  1. API 및 서비스 → OAuth 동의 화면에서 앱을 내부용으로 설정합니다.
  2. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID를 선택합니다.
  3. 애플리케이션 유형은 웹 애플리케이션으로 선택합니다.
  4. 승인된 리디렉션 URI에 위 1번의 주소를 그대로 붙여 넣습니다.
  5. 생성된 클라이언트 ID와 보안 비밀을 위 2번에 입력하고 저장합니다.
  6. Google 계정으로 연결을 누르고 공유 드라이브를 소유한 회사 계정으로 승인합니다.
  7. 연결 테스트가 성공한 뒤에만 Google Drive 저장 활성화를 누릅니다.
